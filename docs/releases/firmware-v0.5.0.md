## What's new

- Wi-Fi, pairing, and links over the local network and the Relay.
- A new flash layout that leaves room for updates over the air later. The first update from older firmware moves the box onto it; the voice pack is kept. On its first start the box makes its own key.
- The screen shows how the box is linked: a plug, Wi-Fi waves or a cloud in the top left. The menu gains a NETWORK page, and COMPUTERS → NEW ID gives the box a new identity before it changes hands.
- Also: the state label keeps clear of a third task card.
- Works with VibeBuddy 0.5.0 and later.
