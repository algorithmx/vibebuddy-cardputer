## 新功能

- 盒子不插线也能用了。插上一次就会自动配对；在设置 → 设备里让盒子连上 Wi-Fi 后，同一个网络里走局域网，人在别处时通过 VibeBuddy 中转。插着线时仍优先走 USB，几种方式之间切换不会断开。
- 中转会让盒子的消息经过 VibeBuddy 的服务器，可以在设置 → 通用里关掉。
- 一个盒子同一时间只连一台电脑，另一台电脑可以在设置 → 设备里接管。
- 首次引导里加了 Wi-Fi 设置，Linux 版也有首次引导了。
- 另外：走网络时也能截屏，Linux 设备页可以滚动，加入 Wi-Fi 时会显示成没成功。
- 需要盒子固件 0.5.0，设置 → 设备会提示更新。
