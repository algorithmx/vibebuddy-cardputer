## What's new

- First-run setup can update the box's firmware: if a newer firmware is out when you plug the box in, you can update it right there instead of waiting for a notification.
- First-run setup fits its window again. With five agents, the Connect agents page was cut off at the top and bottom.
- Picking a character during first-run setup now lists the default robot first, as Settings does.
- The Agents tab in Settings scrolls, so the tab bar no longer slides out of the window.

These changes are in the Mac app. The Linux app has no first-run setup, and its settings already scroll.
